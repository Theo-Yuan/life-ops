# 词汇 Skill

## 原则

1. **高频优先** — IELTS 高频词 > 学术词 > 生僻词
2. **间隔重复** — Anki 式复习曲线
3. **语境记忆** — 句子 > 词组 > 单词
4. **可量化目标** — 日/周/月新词量，复习量

## 词汇量目标

| 阶段 | 词汇量 | 对应水平 | 建议素材 |
|------|--------|---------|---------|
| 基础 | 2000-3000 | 初中水平 | 高中词汇表 |
| 进阶 | 3000-5000 | CET-4/6 | IELTS 核心词汇 |
| 目标 | 5000-7000 | IELTS 6.5 | 剑桥真题词汇 + 学术词汇 |
| 熟练 | 7000+ | IELTS 7.0+ | 词根词缀扩展 |

## 推荐工具

- **Anki** — 间隔重复，自定义词库
- **Quizlet** — 单词卡 + 游戏化
- **欧路词典** — 查词 + 生词本
- **Vocabulary.com** — 英语释义 + 语境

## 记忆策略

### 每日流程
```
1. 新词学习（10个/天）
2. 昨日复习（10个）
3. 7天前复习（10个）
4. 30天前复习（10个）
= 日均 40 词操作
```

### 有效方法
1. **语境造句** — 每个新词造 2 个句子（生活 + 学术）
2. **词根词缀** — 学习常见词根（如: bene=good, mal=bad）
3. **话题分类** — 按 IELTS 话题分类（教育/环境/科技/健康）
4. **同反义词** — 学习同组词汇（important / significant / crucial）

### 易错点
- 拼写错误（accommodation, separate, government）
- 词性误用（economic vs economical, affect vs effect）
- 搭配错误（make a decision, NOT do a decision）
