# 口语 Skill

## 原则

1. **流利度优先** — 能连贯表达 > 追求高级词汇
2. **每日输出** — 哪怕 5 分钟也要开口
3. **真实场景** — 结合工作/面试场景练习

## IELTS Speaking 评分维度

| 维度 | 权重 | 6.0 特征 | 6.5 特征 |
|------|------|---------|---------|
| Fluency & Coherence | 25% | 有停顿，但能持续 | 较流畅，有连接词 |
| Lexical Resource | 25% | 足够表达，但有限 | 能使用部分非常用词 |
| Grammatical Range | 25% | 简单句为主 | 复合句，无明显错误 |
| Pronunciation | 25% | 可理解 | 语调自然，少口音 |

## 练习方法

### 方法 1: 影子跟读（Shadowing）
- 材料: BBC 6 Minute English / IELTS 听力音频
- 方法: 延迟 0.5s 跟读，模仿语调
- 时长: 10min/天
- 目标: 发音 + 语调 + 语流

### 方法 2: 自言自语（Monologue）
- 主题: 当日 IELTS Part 2 题目
- 方法: 录音 → 听写 → 优化
- 时长: 5min 录音 + 10min 优化

### 方法 3: 模拟面试
- 找语伴/使用 AI 口语对练
- 重点练习 Part 3 抽象话题

## 工作英语积累

### 日常场景
- Daily standup / 1-on-1 / Code review
- Technical discussion / Architecture proposal
- Presentation / Demo

### 高频表达库
```
"As far as I'm concerned..."
"That's a good point, but..."
"To build on what you just said..."
"In my experience..."
```

## 每日口语流程
```
1. Shadowing (10min)
2. Part 1 快问快答 (5min)
3. Part 2 主题陈述 (5min)
4. 当日表达积累 (5min)
```
