# IELTS 备考 Skill

## 原则

1. **目标导向** — 一切建议围绕 IELTS 6.5（单科 ≥ 6.0）展开
2. **诊断先行** — 先评估强弱项，再制定 plan
3. **可量化** — 每条建议附带可衡量的练习指标

## 评分标准速查

| 技能 | 6.0 标准 | 6.5 标准 | 7.0 标准 |
|------|---------|---------|---------|
| Listening | 答对 23-25 题 | 答对 26-29 题 | 答对 30-31 题 |
| Reading (A类) | 答对 23-25 题 | 答对 26-29 题 | 答对 30-31 题 |
| Writing | 有回应但有限 | 回应较充分 | 充分回应 |
| Speaking | 能交流但受限 | 流畅度提升 | 细节充分 |

## 各科备考策略

### Listening（听力）
- Section 1-2: 生活场景（住宿、旅游、会员）— 必拿分
- Section 3-4: 学术场景（讨论、讲座）— 拉分区
- 练习方法: 精听 + 听写 + 影子跟读
- 推荐: 剑桥雅思真题 13-19

### Reading（阅读）
- 题型: 填空/判断/配对/标题匹配/选择
- 策略: 先读题后读文，定位关键信息
- 速度: 20min/篇，3篇=60min
- 词汇: 累积学术类高频词汇

### Writing（写作）
- Task 1: 图表描述（150字），客观不评论
- Task 2: 议论文（250字），立场清晰
- 评分维度: Task Response / Coherence / Lexical Resource / Grammar
- 练习: 每周至少 2 套完整写作

### Speaking（口语）
- Part 1: 日常话题（2-3 min）
- Part 2: 个人陈述（1-2 min，准备 1min）
- Part 3: 抽象讨论（4-5 min）
- 关键: 流利度 > 大词，地道 > 复杂

## 学习计划模板

### 每日（1h）
```
0-15min  词汇（Quizlet/Anki）
15-30min 听力（Section 精听）
30-45min 阅读（1篇真题+分析）
45-60min 口语/写作（交替）
```

### 每周
- 2 套完整真题模拟
- 1 篇写作批改
- 周末错题回顾
