# 记账预算知识模块

## 概述

学完后你应该能：
- 建立适合自己的记账系统
- 选择合适的预算策略
- 分析消费模式并优化

## 核心概念

### 为什么要记账？
不是每一分钱都要记，而是：
1. **发现盲区** — 「钱去哪儿了」的答案往往让你吃惊
2. **数据驱动决策** — 不是靠感觉省钱，而是看数据找优化空间
3. **预算的基础** — 没有历史数据，预算就是拍脑袋

### 消费分类体系

```
收入:
  ├── salary / bonus / investment / side_hustle / gift

支出:
  ├── housing     → 房租/房贷/物业/水电燃
  ├── food        → 三餐/外卖/零食
  ├── transport   → 公交/加油/打车/停车
  ├── shopping    → 服饰/数码/家居
  ├── entertainment → 电影/游戏/旅游/社交
  ├── health      → 医疗/健身
  ├── education   → 知识付费
  ├── insurance   → 保险
  └── other
```

### 预算策略

**50/30/20 法则（推荐入门）**
- 必需支出 50%（住房、餐饮、交通、医疗）
- 可选消费 30%（购物、娱乐、旅游）
- 储蓄投资 20%（定投、存款、保险）

**零基预算（进阶）**
每月所有收入从零分配，适合想精细控制的用户

**信封预算法（特定场景）**
现金分类装信封，适合容易超支的品类

## 学习要点

1. **找到适合你的记账粒度** — 有人喜欢每笔都记，有人只看大类。正确的方法是能坚持下去的方法
2. **关注结构而非绝对值** — 支出结构是否合理比花多少钱更重要
3. **预算要留弹性** — 100% 严格执行的预算很难坚持，给自己留 10-15% 的缓冲
4. **趋势比单月重要** — 看 3-6 个月的支出趋势，而不是纠结某个月超支
