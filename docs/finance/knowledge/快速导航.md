# 📚 财富知识库 — 快速导航

> **项目定位：先学习，后建模。**
> Agent 入口：从这里判断需要加载哪个知识文件。

## 知识库结构

| 文件 | 内容 | 适合场景 |
|------|------|----------|
| [核心概念.md](核心概念.md) | 财务自由、复利、资产配置、风险 | 基础概念学习、制定策略 |
| [实践方法.md](实践方法.md) | 定投、再平衡、保险、税务 | 实操指导、优化方案 |
| [学习路径.md](学习路径.md) | 从入门到精通课程大纲 | **首次启动必读**，规划学习计划 |
| [评估体系.md](评估体系.md) | 知识检验、阶段测验 | 检验理解程度、发现盲区 |
| [金融产品与市场.md](金融产品与市场.md) | 产品光谱、市场结构、交易术语 | **参考手册**，学到对应内容时查阅 |
| [来源文献.md](来源文献.md) | 书籍/论文/文章来源 | 验证知识、深入学习 |
| _inbox/ | 原始收集暂存区 | 待整理的新知识 |

## 场景 → 加载策略

```
【首次对话】                           → 快速导航 + 学习路径 + profile
用户问 "什么是 X"                      → 01-核心概念
用户问 "我该怎么做 X"                  → 02-实践方法
用户问 "我想学理财，从哪里开始"        → 03-学习路径
学习完一个阶段                         → 04-评估体系（做测验）
用户问 "XX 产品/基金/股票是什么"       → 05-金融产品与市场（参考手册）
用户在看 K 线/交易软件                 → 05-金融产品与市场（交易术语章节）
用户问 "这个说法靠谱吗"                → 99-来源文献
```
