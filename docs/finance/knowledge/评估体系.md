# 📝 知识评估体系

> 用于检验学习效果，发现知识盲区。
> Agent 在完成每个阶段后自动评估，也可按需随时测验。

## 评估方式

### 1. 概念理解题
检验是否真正理解了核心概念，而非死记硬背。

**示例**：
```
Q: 为什么说「风险 ≠ 波动」？
A: 波动是价格的短期上下起伏，而真正的风险是永久性资本损失。
   一个资产波动大不等于一定会亏钱，但在低谷被迫卖出才会造成永久损失。
   所以对于长期投资者来说，波动是朋友（可以低价买入），不是风险。
```

### 2. 计算应用题
把概念应用到具体数字中。

**示例**：
```
Q: 你现在 25 岁，每月定投 2000 元到年化 8% 的指数基金。
   到 60 岁时你投入了多少本金？最终有多少钱？
   （答案: FV=2000×12×((1+0.08/12)^(35×12)-1)/(0.08/12) ≈ 458 万）
```

### 3. 案例分析
给一个真实或假设场景，让用户分析。

**示例**：
```
Q: 小王有 10 万存款，听说最近某股票涨得很好想全仓买入。
   他现在的资产配置应该是什么样？有什么风险？
```

### 4. 反思题
连接知识和个人情况。

**示例**：
```
Q: 学了资产配置后，看看你自己现在的资产分布。
   有什么风险？你会怎么调整？
```

## 阶段测验

### 初级结业（第 1-6 课后）

**核心检验**：
1. 用自己的话解释「复利」和「72 法则」
2. 解释为什么指数基金 + 定投适合大多数人
3. 设计一个基于你个人情况的简单资产配置
4. 市场突然跌了 20%，你应该怎么做？为什么？

**通过标准**：能清晰解释以上 4 个问题，不需要 Agent 纠正概念性错误。

### 中级结业（第 7-12 课后）

**核心检验**：
1. 为一个漂移的资产组合做再平衡计算
2. 评估自己的保险覆盖，指出缺口
3. 计算自己的 FIRE 目标及所需年限
4. 识别自己在投资中的行为偏差
5. 制定自己的月度财务检查清单

**通过标准**：能独立完成以上任务，Agent 仅做补充建议而非纠正。

### 高级评估

**形式**：给定一个投资案例，用户独立完成分析报告，包含：
- 资产配置评估
- 风险分析
- 优化建议
- 执行计划

Agent 作为 reviewer 反馈。

## 选择题题库

### 初级

**Q1**: 复利的 72 法则可以用来计算什么？
> A. 投资回本所需时间  
> B. 本金翻倍所需时间  
> C. 每年收益率  
> D. 通胀率  
> ✅ **B**

**Q2**: 以下哪个是真正的投资风险？
> A. 价格每天波动  
> B. 新闻报道说市场要跌  
> C. 永久性资本损失  
> D. 短期浮亏  
> ✅ **C**

**Q3**: 资产配置中，股票和债券组合的主要优势是什么？
> A. 收益总是更高  
> B. 两者相关性低，可降低组合波动  
> C. 债券永远不亏钱  
> D. 不需要再平衡  
> ✅ **B**

**Q4**: 指数基金相比主动基金的最大优势是？
> A. 收益总是更高  
> B. 费用更低，长期复利效应明显  
> C. 基金经理更聪明  
> D. 只买涨不买跌  
> ✅ **B**

**Q5**: 市场突然下跌 20%，定投的人应该怎么做？
> A. 停止定投，等反弹再买  
> B. 卖出所有持仓止损  
> C. 继续定投，甚至可以考虑加码  
> D. 换成债券  
> ✅ **C**

### 中级

**Q6**: 资产再平衡的核心原理是什么？
> A. 频繁交易赚差价  
> B. 强制低买高卖，维持风险水平  
> C. 预测市场走势  
> D. 减少交易次数  
> ✅ **B**

**Q7**: 以下哪种负债应该优先偿还？
> A. 房贷 3.5%  
> B. 信用卡循环 18%  
> C. 助学贷款 2%  
> D. 车贷 4%  
> ✅ **B**

**Q8**: FIRE 运动中的 4% 法则指的是什么？
> A. 每年收益 4%  
> B. 每年提取初始本金的 4%，30 年大概率不耗尽  
> C. 每年存收入的 4%  
> D. 投资组合增长 4%  
> ✅ **B**

**Q9**: 定投钝化是什么意思？
> A. 定投时间太长不想继续了  
> B. 随着本金增大，每月新增定投对总资产影响变小  
> C. 定投收益变低了  
> D. 市场不波动了  
> ✅ **B**

**Q10**: 以下哪个是"损失厌恶"偏差的表现？
> A. 只买自己熟悉的股票  
> B. 亏损 1000 元的痛苦 > 盈利 1000 元的快乐  
> C. 跟随大流投资  
> D. 过度自信自己的判断  
> ✅ **B**

| 我理解为什么指数基金 + 定投适合大多数人 | ⚪⚪⚪⚪⚪ |
| 我知道市场下跌时应该怎么做 | ⚪⚪⚪⚪⚪ |
| 我能计算一个漂移的组合并做再平衡 | ⚪⚪⚪⚪⚪ |
| 我知道自己的保险覆盖缺口 | ⚪⚪⚪⚪⚪ |
| 我了解 FIRE 的概念和自己的目标 | ⚪⚪⚪⚪⚪ |

**评分指引**：
- 平均 < 3 分 → 回到对应章节复习
- 平均 3-4 分 → 可以进入下一阶段，但需要巩固
- 平均 > 4 分 → 掌握良好，可以进阶

## 日常检验

每次学习后，Agent 可以做快速检验：

```
"今天讲了资产配置的三个要点。你能用自己的话总结一下吗？"
"你说说看，为什么债券和股票放在一起效果更好？"
```

这是**低压力检验** — 答错了很正常，正好说明需要巩固。
