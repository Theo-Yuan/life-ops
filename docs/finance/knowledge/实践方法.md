# 财富实践方法

## 指数基金定投

### 为什么是指数基金？

- **低费用** — 管理费 0.1-0.5%，主动基金 1-2%。30 年差距巨大
- **分散化** — 买入整个市场，避免个股风险
- **不依赖基金经理** — 避免风格漂移和人事变动
- **长期跑赢多数主动基金** — 标普 SPIVA 报告显示，超过 80% 的主动基金 10 年跑输基准 [来源: S5]

### 定投策略

```
定投金额 = (月收入 - 月支出) × 储蓄投资比例
推荐比例：月收入的 10-30% 用于长期定投
```

**定投频率**：月投 vs 周投 — 长期收益差异极小，选最方便的方式。

**钝化应对**：随着本金增大，每月定投对总资产的边际影响下降。此时应关注：
1. 增加定投金额（随收入增长）
2. 从「攒份额」转向「再平衡」
3. 组合管理重于新增投入

### 市场下跌时怎么办？

> **定投最大的优势就是在下跌时买入更多份额。** 不要停扣，不要恐慌。

```
市场跌 20% → 你的定投买到更多份额
市场涨回来 → 那些便宜份额带来超额收益
```

## 应急资金

> 在投资之前，**先存够应急资金**。这不是可选项，是必须项。

### 存多少？

| 情况 | 建议月数 | 原因 |
|------|---------|------|
| 工作稳定、家庭负担小 | 3 个月支出 | 最低保障 |
| 自由职业/收入波动 | 6 个月支出 | 缓冲不确定期 |
| 单一收入家庭 | 6-12 个月支出 | 更高的安全性 |

### 放哪里？

```
第一梯队（50%）：货币基金     → 随时可取，收益 1.5-2%
第二梯队（50%）：短期定存/R2理财 → 1-3 个月到期，收益 2-3%
```

**绝对不要**把应急资金投入股票/基金。应急资金的功能是**流动性**和**安全性**，不是收益。

### 什么时候用？

仅用于**真正的紧急情况**：
- 失业 / 收入中断
- 重大疾病（医保覆盖外的部分）
- 紧急大额支出（如突发维修）

**不是**用于：换手机、旅游、凑首付。

## 债务偿还

### 好负债 vs 坏负债

| | 利率 | 用途 | 策略 |
|--|------|------|------|
| 房贷 | 3-4% | 买入资产 | 正常还，有余钱可提前还 |
| 助学贷款 | 0-3% | 投资自己 | 最低还款即可 |
| 信用卡循环 | 15-18% | 消费 | **立即还清**，优先级最高 |
| 消费贷 | 8-15% | 消费 | 尽快还清 |

### 偿还策略

**雪球法（Snowball）** — 先还最小额的债，获得正向反馈
```
适合：需要心理激励的人
优点：每一笔还清都有成就感
```

**雪崩法（Avalanche）** — 先还利率最高的债，总利息最少
```
适合：理性计算、能坚持的人
优点：总利息支出最少
```

> 两者都比「每月最低还款」好无数倍。选一个你能坚持的。

### 投资 vs 还债

| 债的利率 | 建议 |
|---------|------|
| < 4% | 正常还债，多余的钱去投资（长期投资收益 > 4%） |
| 4-8% | 均衡分配，一半还债一半投资 |
| > 8% | **优先还债**，还清再投资（没有任何投资能稳定跑赢 8%） |

## 资产再平衡

### 为什么要再平衡？

资产配置会随时间漂移。股票涨得多 → 股票占比越来越高 → 风险超出预期。

**举例**：
```
目标配置：股票 70% / 债券 30%
一年后股票涨 20%，债券跌 5%
→ 实际变成：股票 76% / 债券 24%
→ 风险已经偏离你的初衷
```

### 再平衡的方法

| 方法 | 操作 | 频率 | 适合人群 |
|------|------|------|---------|
| 时间法 | 每季度/半年调回目标比例 | 固定周期 | 大多数投资者 |
| 阈值法 | 偏离超过 5% 时再平衡 | 按需 | 主动管理型 |
| 混合法 | 固定周期检查，超限才动 | 半年检视 | **推荐** |

### 再平衡实操案例

```
初始组合：10 万 → 股票 7 万 + 债券 3 万（70/30）
一年后变化：
  股票涨至 8.4 万（+20%）
  债券跌至 2.85 万（-5%）
  总资产：11.25 万
  实际比例：股票 74.7% / 债券 25.3%

再平衡操作（回归 70/30）：
  目标股票：11.25 × 70% = 7.875 万
  需要卖出股票：8.4 - 7.875 = 0.525 万
  用卖出的钱买入债券：2.85 + 0.525 = 3.375 万

结果：自动实现「卖出涨多的，买入跌了的」
```

这就是再平衡的魔力 — **强制低买高卖**。

## 保险配置

### 保险的目的

> 保险不是为了赚钱，而是为了防止 **因意外返贫**。

### 配置优先级

```
社保 → 医疗险 → 重疾险 → 寿险 → 意外险 → 理财险
```

| 险种 | 作用 | 建议保额 | 优先级 |
|------|------|---------|--------|
| 社保医疗 | 基础保障 | — | ⭐⭐⭐⭐⭐ |
| 百万医疗险 | 大额医疗报销 | 100-600 万 | ⭐⭐⭐⭐⭐ |
| 重疾险 | 患病失能补偿 | 年收入 3-5 倍 | ⭐⭐⭐⭐ |
| 定期寿险 | 家庭支柱身故保障 | 房贷+5 年支出 | ⭐⭐⭐ |
| 意外险 | 意外伤残/身故 | 50-100 万 | ⭐⭐⭐ |
| 理财险（年金/增额寿） | 长期储蓄 | — | ⭐（先投资再考虑） |

### 保费预算

年保费 ≈ 年收入的 5-10%。超过 10% 可能会影响正常储蓄投资。

## 税务优化

### 中国个人投资者的税务优化途径

- **个人养老金账户** — 每年 12,000 元额度，递延纳税，适合税率 10%+ 的人群
- **公积金** — 租房或买房可提取，利率优惠
- **基金持有满 1 年免分红税**
- **股票持有满 1 年免红利税**
- **可转债/国债利息免税**

### 原则

> 不要因为税务原因做糟糕的投资决策。税务优化是 **锦上添花**，不是核心策略。

## 记账方法

### 为什么记账？

不是要你每分钱都记，而是：
1. **发现盲区** — "钱去哪儿了"的答案往往让你吃惊
2. **预算的基础** — 没有历史数据，预算就是拍脑袋
3. **支出意识** — 开始记账后，非必要消费自然减少

### 推荐实践

```
简单模式：每月只看支付宝/微信账单（30 分钟）
标准模式：每周记一次大类支出（10 分钟/周）
精细模式：每笔都记（5 分钟/天，不推荐长期）
```

### 频率建议

```
每日/每周：记录支出
每月：检查预算执行（10 分钟）
每季：净值追踪 + 资产再平衡（30 分钟）
每年：全面财务体检 + 目标回顾（1 小时）
```

### 常用工具（推荐组合）

- **日常消费** — 支付宝/微信自带账单（省心）
- **净值追踪** — 每季度用 Excel/Google Sheets 手动更新一次
- **投资追踪** — 券商 App 自带持仓功能
- **进阶** — 等掌握知识后，用本项目的自动化脚本

## 常见错误

```
❌ 追涨杀跌              → ✅ 定投 + 再平衡
❌ 频繁交易              → ✅ 降低交易频率，减少费用
❌ 过度集中              → ✅ 分散到不同资产类别
❌ 忽视费用              → ✅ 选择低费率产品
❌ 没有应急资金          → ✅ 保持 3-6 个月支出在货币基金
❌ 过度自信              → ✅ 承认自己无法预测市场
❌ 把「保险」当「投资」  → ✅ 保险和投资分开
```
