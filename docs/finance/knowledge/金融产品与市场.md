# 金融产品与市场

> 参考手册，按需查阅。不是一次性读完的 — 在哪看到不懂的术语就翻回来看。

## 金融产品光谱

从低风险到高风险排列：

```
低风险                     →                    高风险
货币基金 → 债券 → 混合基金 → 指数基金 → 个股 → 衍生品
低收益                                           高收益潜力
```

---

### 货币市场产品

| 产品 | 年化收益 | 风险 | 流动性 | 起投 |
|------|---------|------|--------|------|
| 活期存款 | 0.2-0.35% | 极低 | 随时 | 0 |
| 货币基金（余额宝等） | 1.5-2.5% | 极低 | 随时（T+0/1） | 1 元 |
| 国债逆回购 | 1-3%（波动大） | 极低 | 1-182 天 |
| 银行 T+0 理财 | 2-3% | 低 | 随时 | 1 万 |

**货币基金**= 实质上是短期债券 + 银行存款的组合。历史上极少亏损（美国出现过 1-2 次），适合放应急资金。

**国债逆回购**= 你把钱借给别人，别人用国债做抵押。本质是无风险收益，月底/年底收益率常飙高。

---

### 债券

债券本质是**借条** — 发行者向你借钱，到期还本付息。

| 类型 | 发行者 | 风险 | 收益 | 特点 |
|------|--------|------|------|------|
| 国债 | 中央政府 | 极低（国家信用） | 2-3% | 无风险利率锚点 |
| 地方债 | 地方政府 | 低 | 2.5-3.5% | 地方基建融资 |
| 金融债 | 银行等机构 | 低-中 | 2.5-4% | 同业间借贷 |
| 企业债/公司债 | 企业 | 中-高 | 3-8% | 风险看企业资质 |
| 可转债 | 上市公司 | 中 | 1-2%利息+转股权 | ⚡ 下有保底上不封顶 |

**债券价格 vs 利率是反比关系**：
```
利率上升 → 老债券吸引力下降 → 价格跌
利率下降 → 老债券更值钱 → 价格涨
```

**久期（Duration）**：衡量债券对利率变化敏感度的指标。久期越长，价格波动越大。

**可转债（Convertible Bond）**：
- 可以在约定时间按约定价格转换成股票
- 发行时就约定好了转股价
- 如果股价涨 → 转成股票赚差价
- 如果股价跌 → 持有到期拿本息
- 下有保底（债性），上不封顶（股性）
- ⚠️ 不是没有风险：正股爆雷时可转债也会大跌

### 基金

基金 = **汇集很多人的钱，交给专业团队统一投资**。

#### 按投资标的分类

| 类型 | 投资对象 | 风险 | 预期收益 | 适合 |
|------|---------|------|---------|------|
| 货币型 | 货币市场产品 | 极低 | 1.5-2.5% | 放零钱/应急资金 |
| 债券型 | 80%+ 债券 | 中低 | 3-5% | 稳健配置 |
| 混合型 | 股+债灵活调配 | 中 | 5-10% | 股债一把抓 |
| 股票型 | 80%+ 股票 | 高 | 7-15% | 长期增值 |
| 指数型 | 跟踪特定指数 | 高（同指数） | ≈ 指数收益 | 被动投资首选 |

#### 按运作方式分类

| 类型 | 份额是否固定 | 申赎方式 | 交易场所 | 例子 |
|------|-------------|---------|---------|------|
| **开放式基金** | 不固定 | 每日按净值申赎 | 基金公司/三方平台 | 大多数主动基金 |
| **封闭式基金** | 固定 | 到期前不能赎回 | 交易所买卖 | 定开型基金 |
| **ETF（交易型开放式）** | 不固定 | 场内像股票一样买卖 | 交易所 | 510050（50ETF） |
| **LOF（上市型开放式）** | 不固定 | 既可按净值申赎，也可场内买卖 | 两者都可 | 混合型 |
| **QDII** | 不固定 | 申赎 T+2 | 平台/交易所 | 投资海外 |

**ETF（Exchange Traded Fund）** — 本知识库反复推荐的产品：
- 像股票一样实时买卖
- 管理费极低（0.15-0.5%）
- 持仓透明（每天公布）
- 跟踪指数，不依赖基金经理

#### 基金费用

```
买入时（申购费）：    0-1.5%（三方平台打 1 折 → 0.15%）
持有期间（管理费）：  0.1-1.5%/年（指数最低，主动最高）
持有期间（托管费）：  0.05-0.25%/年
卖出时（赎回费）：    0-1.5%（持有越久越低，1 年以上多数免）
```

**⚠️ 费用对长期收益的影响巨大**：

```
假设投入 10 万，年化 8%，30 年后：
管理费 0.15%（ETF） → 终值 97 万
管理费 1.5%（主动） → 终值 72 万
差额：25 万
```

**指数基金 vs 主动基金**：

| | 指数基金 | 主动基金 |
|--|---------|---------|
| 管理费 | 0.1-0.5% | 0.8-1.5%+业绩报酬 |
| 经理影响 | 无（跟踪指数） | 大（换经理≈换基金） |
| 透明度 | 持仓每日公布 | 每季度公布前 10 大 |
| 长期胜率 | — | 80%+ 跑输基准（SPVIA） |

### 股票

股票 = **公司的所有权凭证**。持有股票 = 成为公司股东。

#### A 股市场层次

| 板块 | 交易所 | 定位 | 涨跌幅 | 门槛 |
|------|--------|------|--------|------|
| 主板 | 上海/深圳 | 大型成熟企业 | ±10% | 无 |
| 创业板 | 深圳 | 成长型创新企业 | ±20% | 2 年经验+10 万 |
| 科创板 | 上海 | 硬科技企业 | ±20% | 2 年经验+50 万 |
| 北交所 | 北京 | 专精特新中小企 | ±30% | 2 年经验+50 万 |

⚠️ 涨跌幅越大 ≠ 越容易赚钱，是风险越大。

#### 港股

- **交易时间**：9:30-16:00（中午不休）
- **T+0**：当天买的当天可卖
- **T+2**：资金要 2 个工作日后到账
- **无涨跌幅限制**：一天跌 90% 是可能的
- **港股通**：内地投资者可以直接买港股（50 万门槛）

#### 美股

- **交易时间**：北京时间 21:30-04:00（夏令时），22:30-05:00（冬令时）
- **T+0**：当天可买卖
- **T+2**：资金结算
- **无涨跌幅限制**
- **盘前盘后交易**：正式开盘前后也可交易

#### A 股的特别机制

**T+1**：今天买入的股票，明天才能卖出。这是 A 股和港美股最大的区别。

**涨跌停板**：
- 主板：±10%
- 创业板/科创板：±20%
- ST 股：±5%
- 新股上市首日：±44%

**熔断机制**：2016 年短暂实行后取消，目前 A 股没有指数熔断。

#### 股票分类

| 名目 | 含义 |
|------|------|
| A 股 | 内地上市，人民币交易 |
| H 股 | 香港上市的内地公司 |
| B 股 | 内地上市，外币交易（已边缘化） |
| 红筹股 | 境外注册、香港上市的内地公司 |
| N 股 | 美国上市（纽约）的中概股 |
| ST / *ST | 连续亏损被特别处理 / 有退市风险 |

### 衍生品

衍生品 = 价值**衍生**自其他资产（股票、指数、商品）的金融产品。

| 品种 | 本质 | 风险 | 适合 |
|------|------|------|------|
| 期货 | 约定未来某时间按约定价格买卖 | 高（杠杆） | 专业投资者/套保 |
| 期权 | 买入未来某时间按约定价格买卖的权利 | 中高（卖方风险极大） | 专业投资者 |
| 权证 | 类似期权，已基本退出 A 股 | 高 | — |
| 股指期货 | 以指数为标的的期货 | 高 | 对冲+投机 |

**⚠️ 对于普通投资者**：
- 期货和期权自带杠杆，可能**亏完本金还倒欠**
- 不要碰你不理解的产品
- 本知识库不推荐普通个人投资者交易衍生品

**融资融券（两融）**：
- **融资**= 向券商借钱买股票（看多）
- **融券**= 向券商借股票卖（看空）
- 门槛：50 万资产 + 6 个月经验
- ⚠️ 杠杆是把双刃剑，会放大亏损

### 其他产品

**REITs（房地产信托投资基金）**：
- 投资收租型房地产（写字楼、商场、仓储）的基金
- 收益来源：租金 + 增值
- A 股 REITs 2021 年推出，有 ±30% 涨跌幅限制
- 适合：想配置不动产但不想买房的投资者

**结构化产品**：
- 通常是「固定收益 + 衍生品」的组合
- 例子：保本型结构化产品（本金安全，收益挂钩指数）
- 结构复杂，一定要看清条款

**保险产品（投资型）**：
- 年金险、增额终身寿、万能险、投连险
- 本知识库立场：**先保障后理财，不要用保险产品做投资**

## 金融市场

### 一级市场 vs 二级市场

```
一级市场 = 新发行市场（IPO）
  公司发行股票/债券 → 投资者认购
  钱流到发行人手里

二级市场 = 流通交易市场（我们平时买卖的地方）
  投资者之间互相买卖
  钱不流到发行人手里
  流动性、价格发现
```

**IPO（首次公开发行）**：公司第一次公开卖股票。

**打新（申购新股）**：
- A 股：历史上中签≈稳赚，但需要持仓市值
- 港股/美股：可能首日破发，不是稳赚的


### 港股市场

- **交易所**：香港交易所（HKEX）
- **指数**：恒生指数（HSI）、恒生科技指数
- **特色**：国际化程度高，机构投资者主导
- **内地投资者参与**：港股通（50 万门槛），或直接香港开户
- **交易品种丰富**：窝轮（权证）、牛熊证、REITs 等

---

### 美股市场

- **交易所**：NYSE（纽约）、NASDAQ（纳斯达克）、AMEX（美交所）
- **指数**：标普 500（SPY）、纳斯达克 100（QQQ）、道琼斯（DIA）
- **交易单位**：股（可以买 1 股，不用买 100 股）
- **内地投资者参与**：
  - 通过 QDII 基金买入（最简单，无门槛）
  - 开立境外券商账户（如盈透、富途、老虎）
  - 需境外银行卡出入金（外汇管制限制）

## 交易实操

### 订单类型

| 类型 | 含义 | 使用场景 |
|------|------|---------|
| 市价单 | 以当前最优价格立即成交 | 着急买入/卖出 |
| 限价单 | 指定一个价格，只有到那个价才成交 | 不着急，等好价格 |
| 止损单 | 价格跌到某价位自动卖出 | 控制亏损 |
| 止损限价单 | 止损 + 限价的组合 | 精准控制 |

**建议**：
- 买入用限价单，不要追高
- 长期持有不用盯盘，设置限价挂单即可
- 不要用市价单在大涨/大跌时追进（成交价可能远偏离预期）

### 交易费用（A 股）

```
佣金：万分之 1-3（最低 5 元）
印花税：万分之 5（仅卖出时收，2024 年标准）
过户费：万分之 0.1
规费：含在佣金里

买 1 万元股票 ≈ 总费用 2-5 元
```

⚠️ **频繁交易的最大敌人不是看错方向，是费用**：
```
每月交易 5 次，一次费用 5 元
一年交易费 = 5×5×12 = 300 元
看似不多？如果本金 10 万，300 元 = 0.3%
如果持有不动，这 0.3% 就在复利中多赚了
```

### 重要术语速查

| 术语 | 含义 |
|------|------|
| IPO | 首次公开发行 |
| 定向增发 | 向特定投资者增发新股 |
| 分红/派息 | 公司把利润分给股东 |
| 除权除息 | 分红后股价调整，总资产不变 |
| 送股/转增 | 股份增多，每股价值降低 |
| 回购 | 公司用自己的钱买回股票 |
| 解禁 | 限售股到期可以卖了（通常是利空） |
| 大宗交易 | 单笔大额交易（不经过集合竞价） |
| 龙虎榜 | 异常波动时的买卖席位公布 |
| 北上/南下 | 外资通过港股通买 A 股 / 内资买港股 |
| 主力/主力资金 | 大资金（机构/游资） |
| 散户 | 个人投资者 |
| 仓位 | 你投入股票/基金的钱占总可投资金的比例 |
| 建仓/加仓/减仓/清仓 | 买入/增加/减少/全部卖出 |
| 做多/做空 | 买涨 / 卖跌 |
| 杠杆 | 借钱投资（放大收益也放大亏损） |
| 爆仓 | 杠杆后亏损超过保证金，被强制平仓 |
| 套利 | 利用不同市场/产品的价差获利 |
| 对冲 | 用相反方向的头寸降低风险 |
| 回测 | 用历史数据测试策略表现 |
| Alpha | 跑赢基准的超额收益 |
| Beta | 相对于市场的波动程度 |

## 学习路径中的位置

本文件是**参考手册**性质，不是一课独立课程。建议在以下时机查阅：

- **第 1 课之前**：大致浏览产品光谱，了解有什么
- **第 5 课（指数基金）**：细读基金部分，理解 ETF/开放式/指数型的区别
- **第 7 课（应急资金）**：看货币市场产品部分
- **开始买股票时**：读股票 + 交易实操部分
- **遇到看不懂的术语**：查重要术语速查表
