# 资源推荐

## 基线评估工具（备考第一步——务必先做）

> **目标**: 获得客观的听力、阅读、写作、词汇量基线分数，指导后续学习计划

| 工具 | 用途 | 价格 | 说明 |
|------|------|------|------|
| **BC 雅思官方机考模拟** `cdielts.gelielts.cn` | 听力+阅读+写作全科模考 | 免费 | 官方出品，全真机考界面，2.5 小时完整模拟。通过 `chinaielts.org` 进入 |
| **考满分** `ielts.kmf.com/mock/list` | 听力+阅读+写作模考 | 免费 | C5-C21 全套真题，68 套模考，即时评分+诊断 |
| **BC WriteUp** `chinaielts.org/prepare/WriteUp` | AI 写作批改 | 免费 | 官方 AI，四维度评分，最权威的写作评估 |
| **vocabulary-test.com** | CEFR 词汇量测试 | 免费 | 自适应，8 分钟，A1-C2 分级 |
| **myvocab.info/en** (BRAVE) | 词汇量快速测试 | 免费 | IRT 自适应，2 分钟 |

> ⚠️ 基线评估流程：词汇量 → 听力+阅读模考 → 写作模考 → 建立完整画像

## 推荐备考组合

```
当前工具（保留）
  DailyDictation   → 听力核心：每日听写 20-30min
  扇贝单词         → 词汇：每日背 IELTS 词书
  扇贝听力口语     → 听力辅助：精听+泛听积累
  扇贝阅读         → 阅读辅助：碎片时间泛读

必须补充（当前缺口）
  雅思哥           → 口语题库 + 四科机考模考
  剑桥真题 13-21   → 阅读/听力限时刷题
  BC WriteUp       → 写作 AI 批改

推荐补充
  COOLIELTS/鲸听   → 听力答案词听写（王陆语料库）
  墨墨背单词       → 追求极致记忆效果可切换
  咕噜口语         → 精准口语评分反馈
  刘洪波阅读       → 同义替换系统训练
  王陆语料库       → 听力答案词专项
  顾家北写作       → 写作逻辑+结构
```

**月均预算**：~80-100 元（远低于培训班 3000-10000 元/期）

**扇贝生态整体评价**：覆盖约 60% 备考需求。词汇、听力、泛读够用；**写作、全真模考、口语题库完全缺失**，必须外部补充。
