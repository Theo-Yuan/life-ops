# 学习方法和计划

## 词组/搭配专项（Collocations & Phrasal Verbs）

> ⚠️ 用户画像：词汇量 ~8000（C1），但词组储备严重不足。这是中国学习者最常见的瓶颈之一。

### 为什么词组比单词更重要

**1. 母语者用"块"说话，不是用"词"说话**
- 大脑存储的是 prefabricated chunks（预制语块），不是孤立单词
- 例如：母语者不会现场拼凑 "make" + "a" + "decision"，而是直接提取整个 "make a decision"
- 缺乏词组意味着你说英语时始终在"翻译"而非"表达"

**2. 雅思评分直接挂钩**
- **Lexical Resource (LR)** 评分标准明确要求：使用 less common collocations
- "make a suggestion"（常见） → "put forward a proposal"（高分）
- 拼写/语法全对但搭配不自然 → LR 卡在 6.0
- 口语中 "do a mistake" 即使考官完全理解 → 扣分

**3. 中国学习者的特有问题**
- 中文思维直接翻译： "学习知识" → ❌ "learn knowledge" → ✅ "acquire/gain knowledge"
- 中文一个动词对应英语多个搭配： "开" → open the door / turn on the light / start a meeting / hold a party
- 过度依赖单个"大词"而忽略常见搭配的实际语用

**4. 听力/阅读速度的关键**
- 识别 "take into account" 作为一个整体 → 3 个词的认知成本 = 1 个词
- 逐词解析 → 速度慢、易卡壳、错过后文

### 词组的三个层次

| 层次 | 类型 | 示例 | 数量级 |
|------|------|------|--------|
| **核心搭配** | 动词+名词/形容词+名词 | make a decision, heavy traffic, launch a product | ~2000 |
| **短语动词** | 动词+介词/副词 | put off, come across, figure out | ~500 |
| **固定表达** | 整句级惯用语 | at the end of the day, take it with a grain of salt | ~300 |

### 学习方法

#### 原则：永远不要孤立记单词

```
❌ 错误方式：
   单词卡: "decision" → 决定

✅ 正确方式：
   搭配卡: "make a decision" → 做决定
   搭配卡: "reach a decision" → 达成决定
   搭配卡: "a tough decision" → 艰难的决定
   搭配卡: "decision-making process" → 决策过程
```

#### 日常练习方法

**1. 词伙笔记法（Chunk-based Note Taking）**
- 遇到新词 → 立即查搭配词典 → 记录 2-3 个常见搭配
- 工具: [ozdic.com](https://ozdic.com)（免费搭配词典）、[Ludwig.guru](https://ludwig.guru)（例句搜索）
- 示例：
  ```
  issue (n.)
  - address an issue 解决问题
  - raise an issue 提出问题
  - a pressing issue 紧迫的问题
  - the issue at hand 手头的问题
  ```

**2. 反向翻译法（Back Translation）**
- 找一段中文 → 自己翻译成英文 → 对比原文 → 标注搭配差异
- 适合精读 BBC / The Economist 文章时使用
- 重点不是翻译对错，而是发现"原来母语者是这样搭配的"

**3. 影子跟读 + 语块识别（Shadowing + Chunking）**
- 听一句 → 暂停 → 不是重复单词，而是重复"词组块"
- 例：听到 "We need to / take into account / the long-term impact"
  跟读为 3 个块，不是 12 个单词
- 材料: BBC 6 Minute English（语速适中，词组密集）

**4. 主题式词组积累**
- 按话题集中学习，因为同一话题下搭配高度重合
- 例：环境话题 → carbon emissions / renewable energy / tackle climate change / sustainable development
- 对标 IELTS Writing Task 2 话题：教育、科技、环境、健康、社会

#### 学习节奏建议

| 阶段 | 目标 | 时间 |
|------|------|------|
| 诊断 | 自测常用搭配（如 make/do/take/have 搭配） | 1 天 |
| 积累 | 每日 5 个新搭配 + 复习 15 个 | 持续 |
| 激活 | 用学到的搭配造句/写段落 | 每周 3 次 |
| 检测 | 月底搭配自测 50 题 | 每月 1 次 |

## 核心学习理论

### 间隔重复（Spaced Repetition）
- 复习时间点: 1天 → 3天 → 7天 → 14天 → 30天
- 实现工具: Anki 算法
- 适用范围: 词汇、语法点、口语素材

### 输入优先（Comprehensible Input）
- 每天大量可理解输入（听 + 读）
- i+1 原则: 比当前水平略高的材料
- 推荐: 从感兴趣的话题入手

### 输出驱动（Output-driven）
- 学完就用的内容记得最牢
- 写日记/录口语/找语伴
- 日常用英语思考

## 6.5 分学习计划

### 阶段一: 基础补强（1-2月）
- 词汇: 补齐 IELTS 核心 3000 词
- 语法: 系统复习句子结构、时态、从句
- 听力: BBC 6 Minute English 每日精听
- 口语: Shadowing 每日 10min

### 阶段二: 系统备考（3-4月）
- 真题: 剑桥雅思每周 2 套
- 写作: 大小作文各 2 篇/周
- 口语: 按题库练习 Part 1-3
- 词汇: 话题分类词汇积累

### 阶段三: 冲刺模考（1-2月）
- 全真模考: 每周 3 次
- 错题分析: 题型 + 原因 + 对策
- 写作: 限时训练 + 批改
- 口语: 全真模拟

## 每日学习模板

### 2小时方案
```
0-20min   词汇+搭配（Anki复习：单词+词组各一组）
20-40min  听力（精听1个Section + 提取搭配）
40-60min  阅读（1篇真题+分析 + 标注搭配）
60-80min  写作（小作文1篇/大作文半篇）
80-100min 口语（Part 1+2练习）
100-120min 错题+回顾 + 搭配笔记整理
```

### 1小时方案
```
0-15min  词汇+搭配（Anki复习：单词+词组各一组）
15-30min 听力/阅读（交替 + 提取搭配）
30-45min 写作/口语（交替）
45-60min 错题+搭配笔记整理
```
