# 工作英语

> 目标: 能够用英语完成日常工作沟通和技术面试

## 日常沟通

### 晨会（Daily Standup）
```
Yesterday I worked on [task]. I encountered [issue].
Today I'm planning to [task]. I need help with [blocker].
```

### 1-on-1 Meeting
```
- How are you feeling about the current project?
- I'd like to discuss [topic].
- Is there anything I could improve on?
```

### Code Review
```
- This looks good overall. One suggestion: [feedback].
- Could you clarify the logic here?
- LGTM (Looks Good To Me)
```

## 技术面试

### 自我介绍模板
```
Hi, I'm [name]. I have [X] years of experience in [field].
I'm currently working at [company] as a [role].
My main skills include [skill 1], [skill 2], and [skill 3].
I'm interested in this role because [reason].
```

### 技术问答常用表达
```
- In my experience, [approach] works well because...
- One trade-off to consider is...
- To optimize this, I would...
- The time complexity is O(n) because...
```

### STAR 行为面试法
- **S**ituation: 当时的情况
- **T**ask: 需要完成的任务
- **A**ction: 你采取的行动
- **R**esult: 最终结果

## 邮件写作

### 正式邮件框架
```
Subject: [Clear subject line]

Dear [Name],

[Introduction/Context]
[Main request/Information]
[Action needed]

Best regards,
[Your name]
```

### 常用邮件模板
- 请假: I'm writing to request some annual leave from [date] to [date].
- 约会: Would you be available for a 30-minute meeting on [date]?
- 求助: I'm having trouble with [issue]. Could you help me look into it?

## 商务高频搭配（Business Collocations）

> 与通用词汇不同，商务语境下大量使用固定搭配，掌握后可显著提升职场英语自然度。

### 会议相关

| 搭配 | 释义 | 例句 |
|------|------|------|
| schedule a meeting | 安排会议 | Let's schedule a meeting for next Tuesday. |
| chair a meeting | 主持会议 | Sarah will chair the meeting this afternoon. |
| set an agenda | 设定议程 | I've set the agenda for tomorrow's standup. |
| take minutes | 做会议记录 | Could someone take minutes for this session? |
| action items | 待办事项 | Let's review the action items from last week. |
| follow up on | 跟进 | I'll follow up on the budget approval. |
| touch base | 简短沟通 | Let's touch base after the client call. |
| circle back | 回头再议 | We'll circle back to this in Q3. |

### 项目推进

| 搭配 | 释义 | 例句 |
|------|------|------|
| meet a deadline | 赶上截止日期 | We're on track to meet the Friday deadline. |
| push back the deadline | 推迟截止日期 | Can we push back the deadline to Monday? |
| ship a feature | 发布功能 | We're shipping the new search feature tomorrow. |
| roll out | 逐步推出 | We'll roll out the update to 10% of users first. |
| iron out issues | 解决问题 | We need to iron out a few issues before launch. |
| fall through | 落空/泡汤 | The deal fell through at the last minute. |
| ramp up | 加大力度 | We're ramping up hiring for the new team. |

### 沟通汇报

| 搭配 | 释义 | 例句 |
|------|------|------|
| loop someone in | 让某人知情 | Please loop me in on that email thread. |
| flag an issue | 指出问题 | I wanted to flag a potential security concern. |
| give a heads-up | 提前告知 | Just a heads-up — the server goes down at 2 AM. |
| get on the same page | 达成共识 | Let's meet to get on the same page about scope. |
| drill down | 深入分析 | We need to drill down into the conversion data. |
| bottom line | 核心要点/底线 | The bottom line is we're over budget. |

### 评价与反馈

| 搭配 | 释义 | 例句 |
|------|------|------|
| constructive feedback | 建设性反馈 | I appreciate the constructive feedback. |
| room for improvement | 改进空间 | There's room for improvement in the onboarding flow. |
| a steep learning curve | 学习曲线陡峭 | The codebase has a steep learning curve. |
| a deal-breaker | 一票否决因素 | Missing deadlines is a deal-breaker for this client. |
