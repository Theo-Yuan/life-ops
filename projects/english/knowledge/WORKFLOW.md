# 知识库维护协议

## 添加新知识

1. 新建文件放在 `knowledge/` 下，编号格式 `NN-主题.md`
2. 如果内容不成熟 → 放 `_inbox/` 暂存
3. 每次更新在 frontmatter 更新 `updated` 字段
4. 每条知识标注来源引用 `[来源: SX-来源名]`
5. 新来源添加到 `来源文献.md`

## 更新知识

- 若信息变化 → 更新内容 + 修改 `updated`
- 若发现错误 → 修正 + 添加更新说明
- 若知识点扩充 → 考虑拆分新文件

## 维护原则

1. **来源可追溯** — 每条知识都能追到出处
2. **非个人化** — 知识库不存个人数据
3. **定期清理** — 每月检查 _inbox 是否需归档
4. **版本控制** — git 跟踪所有变化
