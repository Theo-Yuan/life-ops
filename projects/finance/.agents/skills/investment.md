# 投资知识模块

## 概述

学完后你应该能：
- 理解各类投资品种的特点和风险
- 构建自己的投资组合
- 评估投资表现并做调整

## 核心概念

### 投资品种光谱

```
低风险低收益             →             高风险高收益
货币基金 → 债券基金 → 混合基金 → 指数基金 → 个股 → 加密货币
```

### 关键指标

| 指标 | 公式 | 说明 |
|------|------|------|
| 收益率 | (市值 - 成本) / 成本 | 简单收益衡量 |
| XIRR | 现金流内部收益率 | 考虑时间价值的真实年化 |
| 最大回撤 | 峰值到谷底最大跌幅 | 风险衡量指标 |
| 夏普比 | (收益 - 无风险利率) / 波动率 | 风险调整后收益 |

### 组合管理核心

```
目标配置 → 执行建仓 → 定期再平衡 → 评估调整
```

## 学习要点

1. **资产配置 > 选股择时** — 长期收益 90%+ 由配置决定
2. **费用是唯一确定的「收益」** — 管理费 1% vs 0.1%，30 年差几十万
3. **分散 ≠ 数量多** — 买 10 只同行业的股票不算分散
4. **再平衡 = 强制低买高卖** — 定期把超配的卖出，买入低配的
5. **回测都是历史，未来不确定** — 回测是用来理解风险，不是预测收益

## 实操模拟

在实盘之前，可以先做模拟练习：

```
给定 10 万元，构建一个股债 60/40 组合
→ 选择具体的指数基金
→ 制定定投计划
→ 设定再平衡规则
→ 模拟不同市场情境下的表现
```
