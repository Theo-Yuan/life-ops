# 资产管理知识模块

## 概述

这是理财学习的一个知识领域。学完后你应该能：
- 理清自己的资产和负债全貌
- 计算净资产并追踪趋势
- 评估自己的财务健康度

## 核心概念

### 资产分类
```
流动资产     → 现金、活期存款、货币基金（随时可用）
投资资产     → 股票、基金、理财、房产（有增值潜力）
使用资产     → 自住房、车（不产生收入但有使用价值）
```

### 负债分类
```
良性负债     → 房贷（资产增值，利率相对低）
中性负债     → 助学贷款（投资自己）
不良负债     → 消费贷、信用卡循环（高利率，消费非资产）
```

### 关键指标
| 指标 | 公式 | 健康范围 |
|------|------|---------|
| 净资产 | 总资产 - 总负债 | 正数，持续增长 |
| 资产负债率 | 总负债 / 总资产 | < 50% |
| 紧急备用金 | 流动资产 / 月支出 | 3-6 个月 |
| 储蓄率 | 月储蓄 / 月收入 | > 20% |

## 学习要点

1. **区分资产和负债** — 资产把钱装进口袋，负债把钱从口袋拿走（《富爸爸穷爸爸》定义）
2. **紧急备用金优先** — 在投资之前，先存够 3-6 个月的生活费
3. **净值比收入更重要** — 收入是流量，净值是存量，存量决定财务安全
4. **定期追踪趋势** — 每月/每季看一次净值变化方向，不要纠结具体数字
