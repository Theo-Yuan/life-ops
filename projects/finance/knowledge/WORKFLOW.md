# 知识库维护协议

## 核心原则

> 知识库 = 纯领域知识，不含用户个人数据。
> 画像（profile.md）= 你的学习目标、财务水平。
> 二者分离，Agent 交叉使用。

## 新增知识流程

```
发现新知识 → 存入 _inbox/（原文+链接）
          → 整理知识点
          → 分配 S 编号
          → 写入对应知识文件
          → 更新 来源文献.md
```

## 文件规范

1. 每个文件一个主题，使用可读叙述体
2. 关键数据 **加粗**
3. 每段知识标注来源 `[来源: SX]`
4. 不含用户个人数据（那是 profile.md 的事）
5. 学习路径（学习路径.md）随知识库扩展同步更新

## 更新频率

- 遇到新的知识点随学随记
- 定期（每月）整理 `_inbox/`
- 数据指标（如历史回撤）每半年检查更新
- 学习路径根据用户反馈持续迭代

## 索引维护

新增/重命名文件后，同步更新 `快速导航.md` 中的文件列表和场景说明。
